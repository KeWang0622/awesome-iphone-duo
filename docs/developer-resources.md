# Duo development resources

Companion resources for people building the next interesting Duo app. Community examples and simulators do not replace physical-device checks or official Apple documentation. Checked October 26, 2026.

- [Apple: prepare and submit Duo apps](https://developer.apple.com/news/?id=kkphp5qo) - Official starting point for current development guidance.
- [iPhone Duo by Examples](https://github.com/artemnovichkov/iPhone-Duo-by-Examples) - Runnable SwiftUI examples for hinge input, reserved screen regions, arrangements, vertical bars, and cover-display accessories.
- [hinge](https://github.com/artemnovichkov/hinge) - Control the iPhone Duo Simulator hinge angle from the command line for repeatable demonstrations and checks.
- [duo-demo](https://github.com/pvinis/duo-demo) - Explore display position, shared state between windows, hinge readings, and a cover-display camera preview in a small SwiftUI app.
- [NativeScript Duo tabs and toolbars](https://github.com/NathanWalker/ns-duo-tab-and-toolbars) - NativeScript sample for adaptive tabs, toolbars, a live hinge dashboard, reserved regions, and simulator test flows.
- [Doan Labs Duo](https://github.com/doan-labs/duo) - Unofficial browser and Tauri foldable-device simulator with a React/TypeScript app SDK and showcase.
- [iPhone Duo Skills (hechen)](https://github.com/hechen/iphone-duo-skills) - Community agent guidance for adapting SwiftUI, UIKit, camera, layouts, scenes, and tests to Duo; links its Apple documentation sources.
- [iPhone Duo Skills (mirzaaghazadeh)](https://github.com/mirzaaghazadeh/iphone-duo-skills) - Community guidance for fold-aware layouts, vertical bars, camera behavior, games, and framework-specific adaptation.
